# ASA 2026 CVICU Pathway ePoster

Static site. One self-contained file: `public/index.html` (no external requests).

## Deploy on Render
1. Push this folder to a GitHub repo.
2. Render dashboard > New > Blueprint (uses `render.yaml`), or New > Static Site with
   build command empty and publish directory `public`.
3. Add a custom domain under Settings > Custom Domains, and point the QR code at that domain.

## Before printing the QR code
Test the final URL on iPhone and Android over cellular.
